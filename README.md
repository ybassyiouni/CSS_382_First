## Idea

Create a website that allows users to see the latest major news in relevance to a set of interests that they share. On your first visit you pick the topics you care about (tech, sports, politics, etc.) and the app builds a personalized news feed around those choices. You can filter by topic, search headlines, bookmark articles, and toggle dark mode.
